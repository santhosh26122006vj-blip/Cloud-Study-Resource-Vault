System Architecture

Cloud Computing Architecture Demonstration

This web application demonstrates a fully serverless, 3-tier cloud computing architecture utilizing Google Cloud and Firebase primitives:

Client Tier

HTML5 + CSS3 + Vanilla JavaScript

Identity Provider

Firebase Authentication (OAuth2/JWT)

Cloud NoSQL DB

Cloud Firestore (Document Database)

Cloud Blob Storage

Google Cloud Storage (Buckets)

Authentication Manages stateful identity tokens and enforces student/admin permissions.
Firestore Database Stores user documents, resource metadata, tags, and personalized favorites.
Firebase Storage Elastic object storage for binary files (PDFs, PPTs, Docs) with secure download URLs.
Security Rules Cloud-native authorization ensuring students modify only their own uploads.
